# Site Vitrine Toolkit

Boîte à outils gardée sous le coude pour créer des sites vitrines plus modernes.

## Installé

- `@shadergradient/react` : fonds dégradés/animés premium.
- `three` : moteur 3D web.
- `@react-three/fiber` : Three.js dans React.
- `@react-three/drei` : helpers 3D prêts à l’emploi.
- `react-device-frameset` : mockups iPhone/Mac/écrans pour présenter un site.
- `framer-motion` : animations propres et rapides.
- `lucide-react` : icônes modernes.
- `vite` + React : base de démo rapide.

## Lancer la démo

```bash
cd /Users/clement/Jarvis/site-vitrine-toolkit
npm run dev
```

Puis ouvrir : http://127.0.0.1:5174

## Utilisation business/prospection

Pour un site vitrine client, rester simple :

1. Hero propre avec un fond animé léger.
2. Bouton contact/devis très visible.
3. Mockup mobile pour montrer que le site est responsive.
4. Quelques animations Framer Motion, pas trop.
5. Éviter la 3D lourde sauf client premium.

## Commandes utiles

```bash
npm run build     # vérifier que tout compile
npm run dev       # travailler en local
npm run preview   # prévisualiser après build
```
