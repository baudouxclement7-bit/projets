APPLI VIERGE — PLANNING RDV OPTIMISÉ

Ouvre index.html dans ton navigateur.

Fonctionnement :
1. Dépose un Excel / planning.
2. L’appli détecte les colonnes principales : Entreprise, Contact, Adresse, Email, Téléphone, Activité, Secteur, Date, Heure, Latitude, Longitude.
3. Elle génère :
   - planning de tournées optimisées,
   - 3 propositions de dates obligatoires par contact,
   - créneaux espacés anti-chevauchement,
   - carte,
   - email TEST sans aucun envoi réel,
   - export Excel enrichi, HTML rempli et JSON validations.

Important :
- Aucun email réel n’est envoyé.
- Les données restent côté navigateur.
- Le géocodage utilise l’API Adresse française si latitude/longitude sont absentes.
- Internet est utile pour SheetJS, Leaflet, la carte et le géocodage.

Fichier modèle : modele_import_planning.xlsx
