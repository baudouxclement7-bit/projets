Fiche mémo — avant le contrôle

Tes cours seulement : équations + second degré. À connaître = définitions. Le reste = savoir s’en servir, pas par cœur.

1. Équations

Vocabulaire

  • Équation : égalité avec une inconnue.
  • Solution : valeur qui marche.
  • Résoudre : trouver toutes les solutions. On écrit S.
  • Aucune solution → S = ensemble vide.

Toujours : d’abord ce qui est interdit (domaine), ensuite on résout.

1er degré

  1. Développer
  2. Isoler les termes avec x
  3. Simplifier
  4. Conclure (écrire S)

Produit = 0

A × B = 0  ⇔  A = 0 ou B = 0

Souvent : tout mettre du même côté, factoriser (identité remarquable), puis la règle, puis S.

Exemple : (2x + 1)(x − 3) = 0 → x = −1/2 ou x = 3.

A² + 4 = 0 : un carré + un nombre positif, souvent aucune solution.

Quotient = 0

A / B = 0  ⇔  A = 0 et B ≠ 0
  1. Valeurs interdites (bas = 0)
  2. Haut = 0
  3. Jeter si ça annule le bas
  4. Écrire S

Exemple : (3x + 1) / (−x + 6) = 0. Interdit : x = 6. Haut : x = −1/3. −1/3 ≠ 6 donc S = { −1/3 }.

« On travaille dans R sauf 6 » ce n’est pas S. S c’est seulement les solutions.

2. Second degré

Définitions à connaître

  • Trinôme : ax² + bx + c avec a ≠ 0. b ou c peuvent être 0 (ex. x² + 2, −4x²).
  • Degré : plus grande puissance encore là. Affine = 1, constante = 0.
  • Racine de P : P(a) = 0. Chercher les racines = résoudre P(x) = 0.
  • Deux polynômes égaux : même degré et mêmes coefficients. Un point commun (P(1) = Q(1)) ne suffit pas.

Forme canonique

P(x) = a (x − α)² + β
α = −b / (2a)    et    β = P(α)

Le sommet de la parabole est S(α , β). L’axe de symétrie est la droite x = α.

Variations et parabole

  • a > 0 : forme U, minimum en x = α, valeur β. Décroît jusqu’à α, puis croît.
  • a < 0 : forme ∩, maximum en x = α, valeur β. Croît jusqu’à α, puis décroît.

Pourquoi : (x − α)² est toujours ≥ 0. Le signe de a décide si la courbe va vers le haut ou vers le bas.

Exemples à savoir refaire

  • (2x + 3)(x − 1) = 2x² + x − 3 → a = 2, b = 1, c = −3. C’est un trinôme.
  • (x + 1)³ − (x − 1)³ = 6x² + 2 → encore un trinôme (même après des cubes).
  • P(x) = 2x³ + 3x² − 16x + 4, P(2) = 0 donc 2 est racine, puis P(x) = (x − 2)(2x² + 7x − 2).

3. Pièges

  • √x ou un quotient → en général pas un polynôme.
  • Ne pas confondre racines et coefficients.
  • Oublier une valeur interdite dans un quotient.
  • Simplifier par x dans x² = 4x sans parler de x = 0.
