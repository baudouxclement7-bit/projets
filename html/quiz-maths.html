Révisions maths

D’après tes fiches (équations + second degré). Une question après l’autre. Tape une réponse, puis « Voir la correction ».

Q1 · définition
Un quotient A / B est nul. Quelle est la condition exacte ?
Correction. Un quotient est nul seulement si le numérateur est 0 et le dénominateur n’est pas 0. Sinon c’est interdit (division par 0).
Q2 · exemple du cahier
Résous :
3x + 1−x + 6 = 0
Correction. Interdit : x = 6 (dénominateur). Numérateur : 3x+1 = 0 → x = −1/3. −1/3 n’est pas 6, donc S = { −1/3 }. Attention : « on travaille dans R sans 6 » ce n’est pas S.
Q3 · définition
Qu’est-ce qu’un trinôme du second degré ?
Correction. f(x) = ax² + bx + c avec a ≠ 0. b ou c peuvent être 0 : x²+2 et −4x² sont des trinômes.
Q4 · exemple à refaire
x ↦ (2x+3)(x−1) est-il un trinôme ? Si oui, a, b, c ?
Correction. (2x+3)(x−1) = 2x² −2x +3x −3 = 2x² + x − 3. Donc a=2, b=1, c=−3.
Q5 · ouverte
Formule de alpha dans la forme canonique ?
P(x) = a(x − α)² + β
Correction. α = −b / (2a) et β = P(α). Le sommet de la parabole est S(α, β).
Q6 · variations
Si a > 0, la parabole est en U. Où est le min, et que fait f autour de α ?
Correction. Minimum en x = α, valeur β. f décroît sur ]−∞ ; α] et croît sur [α ; +∞[.
